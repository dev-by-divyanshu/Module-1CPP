# C++ Object-Oriented Programming Assignment

This repository contains my **C++ Object-Oriented Programming (OOP) Assignment #1** programs. It covers fundamental OOP concepts, functions, references, and practical case studies implemented using C++.

## 📚 Topics Covered

* Object-Oriented Programming (OOP) Concepts
* OOP vs Procedure-Oriented Programming
* Advantages and Disadvantages of OOP
* Classes and Objects
* Data Members and Member Functions
* Encapsulation and Abstraction
* Inheritance and Polymorphism
* Dynamic Binding
* Inline Functions
* Default Arguments
* Reference Variables
* Pass by Value
* Pass by Reference

## 💻 Practical Programs

The assignment includes C++ programs based on real-world applications such as:

* 🏦 **Bank Customer Management**
* 📚 **Library Management System**
* 🏥 **Hospital Patient Management System**
* 🛒 **Online Shopping System**
* 🎓 **Student Result Processing System**
* 💰 **Bank Loan Management System**
* 🔄 **Swapping using Reference Variables**
* ➕ **Arithmetic Operations using Inline Functions**
* 💵 **Simple Interest using Default Arguments**

## 🛠️ Technologies Used

* **Language:** C++

* **IDE:** Visual Studio Code

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone <repository-url>
```

### 2. Open the project in Visual Studio Code

Open the cloned folder in **VS Code**.

### 3. Compile a program

```bash
g++ filename.cpp -o program
```

### 4. Run the program

**Windows:**

```bash
.\program
```

**Linux/macOS:**

```bash
./program
```

The purpose of this assignment is to understand the basic concepts of **Object-Oriented Programming in C++** and apply them to simple real-world problems.

It also provides practical experience with **classes, objects, encapsulation, abstraction, functions, references, and other important C++ concepts**.
